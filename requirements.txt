# Curated from what the code actually imports; the previous file was a raw
# `pip freeze` and carried ~40 unrelated packages.
#
# Pinned, not floored. These are the versions this project was developed and tested
# against. `>=` floors were tried and do not work: a fresh install resolves torch to a
# cu130 build from PyPI, which flash-attn 2.8.3 cannot load (`libcudart.so.12: cannot
# open shared object file`), and drags transformers 4->5, opencv 4->5 and
# huggingface-hub 0->1 across major versions.
#
# transformers is 4.57.0 rather than the 4.51.3 this project was trained with: the demo's
# optional auto-captioner defaults to Qwen3-VL, and `qwen3_vl` support only landed in
# transformers 4.57.0. 4.57.0 was checked against the training/inference paths here --
# project imports, all eight configs, the T5 encoder and the Wan wrappers -- and is clean.
#
# The `+cu128` local versions only exist on the PyTorch index, so they pin the CUDA
# build as well as the version. Install order matters -- flash-attn is NOT listed here
# because it builds against an already-installed torch:
#     pip install -r requirements.txt --extra-index-url https://download.pytorch.org/whl/cu128
#     pip install flash-attn==2.8.3 --no-build-isolation
#
# Optional, both auto-detected at import and not required:
#     flash_attn_interface  (FlashAttention 3, Hopper only; source install)
#     sageattention
