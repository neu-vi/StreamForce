Streams synthetic frames with no model running, over the same transport the demo uses: binary Socket.IO frames with the identical 12-byte header.

Read the rolling rate, not the average. An average over a whole run mixes TCP's warm-up, the steady state and any collapse into one number — which is why the same link reports very different totals for a 30 s and a 60 s run, or for two frame sizes. The rolling figure is the last 5 seconds only, so you can watch it settle; stable says when it has.
